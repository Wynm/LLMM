# خارطة الطريق · Roadmap

المراحل مرقّمة، ولكلٍّ منها **تعريفُ إنجاز** (Definition of Done) قابلٌ للتحقّق.
لا تُعلَّم مرحلةٌ بأنها منجزة إلا إذا مرّت اختباراتها ووُثّقت في سجلّ التطوير.

---

## المرحلة 0 — التأسيس ✅
- [x] مستودعٌ نظيف، `.gitignore`، `requirements.txt`، `Makefile`، `bootstrap.sh`
- [x] وثائق الرؤية والمعمارية وخارطة الطريق
- [x] سجلّ تطويرٍ (Devlog) يوميّ

**الإنجاز:** `make bootstrap && make test` يمرّان على نسخةٍ نظيفة.

## المرحلة 1 — النواة اللغوية `mishkat.text` 🚧
- [x] تطبيع بأربعة مستويات + أرقام هندية + تشكيل + تطويل
- [x] تقطيع كلماتٍ بمواضع، تقطيع جُمل، n-grams
- [x] قائمة إيقاف عربية (300+)
- [x] مُجذِّع خفيف Light-10 + قاسٍ
- [x] استخراج جذر بالأنماط + إعلال
- [x] محلّل موحّد `analyze`
- [x] 40+ اختبار وحدة

**الإنجاز:** تحليل أي جملة عربية يُنتج كلماتٍ مع جذورٍ صحيحة في ≥ 85% من حالات
مجموعة اختبارٍ يدوية.

## المرحلة 2 — المجموعة `mishkat.corpus` 🚧
- [x] مخطّط JSONL + محمّل + تحقّق
- [x] 60+ مستندًا عربيًّا أصليًّا في 12 نطاقًا
- [x] ملفُّ علاقات (حواف الرسم المعرفي)
- [ ] التوسّع إلى 200 مستند

**الإنجاز:** `mishkat stats` يُظهر توزيعًا متوازنًا على النطاقات.

## المرحلة 3 — الاسترجاع `mishkat.index`
- [x] فهرس مقلوب + ترميز postings
- [x] BM25 ثنائي الحقل + تشغيل استعلام (AND/OR/phrase/prefix)
- [x] HNSW من الصفر (بناء + بحث + حذف منطقي)
- [x] RRF للدمج الهجين
- [x] معيار استرجاع (recall@k, MRR, nDCG) على 40 استعلامًا مُعنونًا
- [ ] إعادة ترتيب بـ cross-features

**الإنجاز:** MRR ≥ 0.75 على مجموعة الاستعلامات المعيارية.

## المرحلة 4 — الفضاء الدلالي `mishkat.embed`
- [x] مصفوفة تجاور + PPMI
- [x] SVD مضغوط عشوائيًّا
- [x] جيران الكلمة + تشابه + تمثيل المستند
- [ ] كشف المرادفات تلقائيًّا وتوسيع الاستعلام

**الإنجاز:** جيران «فلك» تحتوي «كوكب/نجم/مجرة» ضمن أعلى 10.

## المرحلة 5 — الرسم المعرفي `mishkat.graph`
- [x] مخزن رسمٍ موسوم بفهرسةٍ مزدوجة
- [x] لغة استعلام (recursive descent) + تنفيذ
- [x] استدلال: تعدٍّ عابر، تناظر، عكس، مسارات
- [ ] كشف تناقضات

**الإنجاز:** استعلامٌ من ثلاث حافاتٍ يُرجع مسارًا صحيحًا موثّقًا.

## المرحلة 6 — المحوّل العصبي `mishkat.lm`
- [x] CharTokenizer + Transformer (NumPy)
- [x] تدريب Adam + clipping + cosine schedule
- [x] توليد temperature / top-k
- [ ] تقييم perplexity على حجزٍ (held-out)
- [ ] تحميل أوزانٍ محفوظة تلقائيًّا

**الإنجاز:** خسارة التدريب تنخفض < 1.6 ونتولّد نصًّا عربيًّا «مقروءًا» جزئيًّا.

## المرحلة 7 — الواجهة `mishkat.api` + `studio`
- [x] FastAPI: /search /doc /graph /stats /lm /health
- [x] استوديو RTL: بحث، إبراز، رسم قوى Canvas، لوحة إحصاءات
- [ ] وضع لوحة المفاتيح الكامل + إتاحة (a11y)
- [ ] تصدير النتائج (JSON/Markdown)

**الإنجاز:** جلسةٌ كاملة في المتصفّح بلا أخطاء في الطرفية.

## المرحلة 8 — الجودة والتشغيل
- [x] pytest + تغطية
- [x] CI على GitHub Actions

- [x] `make bench` لتقرير أداءٍ

## المرحلة 9 — آفاق
- وكيل بحثٍ متعدّد الخطوات (تخطيط ← استعلام ← تقييم ← إعادة صياغة)
- تلخيصٌ استخلاصي (TextRank + MMR)
- تحليل العروض (بحور الخليل) آليًّا
- تصدير رسمٍ معرفيّ إلى DOT/GraphML
- وضعٌ متعدّد اللغات (عربي/إنجليزي) بنفس النواة
