## الطبقات (طبقة تعلو طبقة، ولا تعرف العليا أسرار السفلى)

### 1. `mishkat.text` — النواة اللغوية
لا تبعيات خارجية إطلاقًا (stdlib فقط). تعمل بمعزلٍ عن كل شيء آخر.

| وحدة | مسؤولية |
| --- | --- |
| `normalize.py` | تطبيع Unicode بأربعة مستويات: `display` / `light` / `search` / `strict`؛ إزالة التشكيل والتطويل، توحيد الألف والهمزة والياء والتاء المربوطة، تحويل الأرقام الهندية. |
| `tokenize.py` | تقطيع إلى كلماتٍ بمواضع (offsets) من أجل الإبراز، تقطيع جُملٍ بقواعد عربية (؟ ، ؛ …), توليد n-grams. |
| `stopwords.py` | قائمة إيقاف عربية منسّقة يدويًّا (~300 كلمة) مع استثناءات. |
| `stem.py` | مُجذِّع خفيف (Light-10) بجداول سوابق/لواحق، و`strict` للتجذيع القاسي. |
| `roots.py` | استخراج الجذر بالأنماط الصرفية: مجرّد/مزيد، مع معالجة حروف العلّة (و/ي/ا) وحذف التضعيف. |
| `analyze.py` | واجهة موحّدة تُنتج `Token` بخصائص: `norm`, `stem`, `root`, `kind` (اسم/فعل/حرف), `offsets`. |

### 2. `mishkat.corpus` — المجموعة
مُحمِّل JSONL مع تحقّقٍ صارم من المخطّط، فهرسةٍ بالمعرّفات، وبناء «مستندات» موحّدة
(عنوان + ملخّص + متن + وسوم + نطاق). كلُّ مستندٍ عربيٌّ أصليّ، مكتوبٌ لهذا المشروع.

### 3. `mishkat.index` — الاسترجاع
- `inverted.py`: فهرس مقلوب (term → postings) بترميزٍ مضغوط داخليًّا (varint + delta).
- `bm25.py`: BM25 (k1=1.5, b=0.75) فوق حقلين موزونين (عنوان ×3، متن ×1) + تشغيل الاستعلام.
- `hnsw.py`: HNSW من الصفر: إدخالٌ بطبقات، `M` روابط، `efConstruction`، بحث `ef_search`، دالة مسافة جيب التمام.
- `hybrid.py`: دمجٌ بـ RRF (k=60) بين مسارٍ معجميٍّ ومسارٍ دلاليّ.

### 4. `mishkat.embed` — الفضاء الدلالي
- `cooccur.py`: نافذة انزلاقية، عدّ تجاورٍ متحيّز المسافة.
- `ppmi.py`: تحويل العدّ إلى PPMI.
- `svd.py`: تحليلٌ قيميٌّ مفرد بضغطٍ عشوائي (randomized SVD) على NumPy.
- `space.py`: متجهات الكلمات + متجه المستند (متوسط مرجّح بـ IDF) + جيران.

### 5. `mishkat.graph` — المعرفة
- `store.py`: رسمٌ موجّه موسوم، فهرسةٌ مزدوجة (out/in).
- `query.py`: لغة استعلامٍ صغيرة (recursive descent) مثل:
  `SELECT ?x WHERE ?x --ينتمي_إلى--> (علم_الفلك) LIMIT 10`
- `infer.py`: استدلالٌ بالقواعد: تعدٍّ عابر للعلاقات المتعدّية، تناظر، عكس، واكتشاف مسارات.

### 6. `mishkat.lm` — المحوّل العصبي
Transformer حرفيّ صغير (Self-Attention + LayerNorm + GELU + residuals) مكتوبٌ بـ NumPy،
مع مُحسِّن Adam، وتدريبٍ محلّي، وأخذ عيّناتٍ بـ temperature/top-k.

### 7. `mishkat.api` + `studio`
FastAPI يقدّم JSON، و`studio/` صفحةٌ واحدة بلا خطوة بناء: HTML + CSS + JS خالص،
رسمٌ للقوى على Canvas مكتوبٌ يدويًّا، تصميمٌ عربيٌّ RTL.

## قرارات معمارية (ADR مختصرة)

| # | القرار | البديل المرفوض | السبب |
| --- | --- | --- | --- |
| 1 | بايثون + NumPy | Node/TypeScript كلُّه | النواة العلمية (SVD، Transformer) طبيعتها بايثون؛ والواجهة JS خالص بلا بناء. |
| 2 | JSONL للمجموعة | قاعدة بيانات | قابلية القراءة بـ `git diff`، نقلٌ بلا أدوات، نسخٌ احتياطيٌّ تافه. |
| 3 | HNSW مكتوب يدويًّا | `faiss` | التبعية تُخفي الخوّارزم؛ ونحن نُعلّم كيف يعمل. |
| 4 | SVD مضغوط عشوائيًّا | SVD كامل | O(n·k²) بدل O(n³): يسمح بنموّ المجموعة. |
| 5 | لا مفاتيح API | خدمة سحابية | الاستقلال والخصوصية والشفافية. |
| 6 | واجهة بلا خطوة بناء | React/Vite | يفتح الملف مباشرة، ويُخدم من نفس الخادم، ولا `node_modules`. |
| 7 | كل شيء قابل للاختبار | «سنكتب الاختبارات لاحقًا» | لا شيء يُدمج دون اختبار. |
| 8 | دمجٌ بالدرجات المُطبَّعة | RRF (الشائع) | قياسٌ على 59 استعلامًا: MRR 0.992 مقابل 0.969؛ RRF يعمل على الرتب فيُسوّي بين دليلٍ قويّ وأثرٍ هامشي. RRF يبقى متاحًا للمقارنة. |
| 9 | تقييمٌ بمجموعةٍ مُعنونة | «البحث يبدو جيدًا» | كل قرار دمج يُقاس بـ MRR/Recall/nDCG على `data/eval/queries.jsonl`. |
| 10 | محوّل NumPy صغير | تنزيل نموذجٍ جاهز | الشفافية والاستقلال؛ حدوده معلنة (نموذج توضيحيّ لا محاور). |

## الأداء المستهدف

| العملية | الهدف |
| --- | --- |
| تحميل المجموعة (500 مستند) | < 1.5 ث |
| بناء الفهرس الكامل | < 4 ث |
| استعلام BM25 | < 10 ملّي ث |
| استعلام HNSW (k=10) | < 5 ملّي ث |
| استعلام مركّب (هجين) | < 25 ملّي ث |
| تدريب المحوّل (2000 خطوة) | < 6 دقائق على نواتين |

**الحالة المقيسة (6 نوفمبر 2026):** بناء 14.4 ث (59 مستندًا) · BM25 2.1 ملّي ث ·
HNSW 1.0 ملّي ث · هجين 8.7 ملّي ث · تدريب المحوّل 2200 خطوة في 6.9 دقائق. كلّها
داخل الأهداف عدا زمن البناء (يُحسّن مع تقليل تكلفة SVD).
